# Design

The pack's design, owned by `pack-designer` and critiqued by
`pack-reviewer`. The set grows from Phase 0 and is completed in Phase 1.
The usual set (adapt it to the charter; formats and the quality bar are in
the pack-design skill):

| Doc | Holds |
|---|---|
| `vision.md` | premise, pillars, tone, what the pack is not |
| `story.md` | canon and how each beat is delivered in game |
| `mods.md` | the roster with roles, pillars and integration links |
| `progression.md` | acts, gates, progression graph |
| `integration.md` | recipe and mechanic interconnection matrix, every pack-specific change with its reason |
| `quests.md` | questbook structure, chapter outlines, voice, reward policy |
| `balance.md` | balance targets and the play-time ledger |
| `art.md` | art direction (ramps in `art/palette.json`) and the art inventory with tiers |

`reviews/` holds pack-reviewer critiques (`YYYY-MM-DD-<topic>.md`).
Settled choices are recorded in `docs/decisions/`.
