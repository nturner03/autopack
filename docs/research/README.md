# Research

Fact-finding that design decisions rest on. `mods/<slug>.md` holds one
report per candidate mod (or mod update), written by `pack-mod-researcher`:
the exact version for the pack's Minecraft version and loader, dependencies,
side (decided from the jar), content, recipe types, integration hooks and
known conflicts. Other research (version comparisons, mechanic deep-dives)
goes in topic files here. Reports record facts with sources; the designer
draws conclusions in `docs/design/` and `docs/decisions/`.
